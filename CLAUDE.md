# phejno-plugins

Personal Claude Code plugin marketplace: one plugin per top-level directory, registered in `.claude-plugin/marketplace.json`. Conventions and the test-suite ratchet are in `docs/standards.md`.

## Project docs
Work is tracked in docs/initiatives/<date>-<topic>/ (spec, plan, ledger, journal);
status in docs/STATUS.md, open work in docs/backlog.md.
Save superpowers specs and plans into the initiative folder, not docs/superpowers/.
